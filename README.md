# Rust CLI Tools & Utilities 🦀

A curated collection of command-line tools, utilities, and algorithmic simulations written in Rust.

## 🛠️ Projects Included

| Project | Description | Path |
| :--- | :--- | :--- |
| **fastgrep** | High-performance CLI text search utility inspired by grep | [`projects/fastgrep`](./projects/fastgrep) |
| **todo-cli-rust** | Terminal-based To-Do list manager with colorized output and JSON persistence | [`projects/todo-cli-rust`](./projects/todo-cli-rust) |
| **birthday_problem_simulation** | Monte Carlo simulation of the classic Birthday Paradox | [`projects/birthday_problem_simulation`](./projects/birthday_problem_simulation) |
| **monty_hall_problem_simulation** | Probability simulation exploring the Monty Hall problem | [`projects/monty_hall_problem_simulation`](./projects/monty_hall_problem_simulation) |

## 🚀 Getting Started

Ensure you have Rust and Cargo installed:
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

To run any tool:
```bash
cd projects/<project-name>
cargo run --release
```
